# Contributing

Thanks for your interest in contributing to Visionary Aide.

## Development Setup

```sh
npm install
cp .env.example .env
npm run dev
```

## Pull Requests

- Keep changes focused and easy to review.
- Add or update tests when behavior changes.
- Run `npm run lint` and `npm run test` before opening a pull request.
- Do not commit secrets, generated build output, or local environment files.

## Issues

When reporting a bug, include:

- What happened and what you expected.
- Steps to reproduce.
- Browser, OS, and Node.js version when relevant.
- Console or terminal errors when available.
